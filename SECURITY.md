# Security Policy

## Vulnerability Disclosure Protocol

We take the security of the **SecureFlow Platform** seriously. If you identify a security vulnerability or exploit inside this project, please do NOT create a public issue. Instead, report it privately to our security coordination team.

---

## Supported Versions

Only the latest active branch is supported with security patches:

| Version | Supported |
| :--- | :--- |
| v1.x.x | Yes (Active) |
| < v1.0.0 | No |

---

## Reporting a Vulnerability

Please email security reports to `security@secureflow.internal` (mock address). Provide:
- A description of the vulnerability.
- Steps to reproduce or proof-of-concept logs.
- Potential impact assessments.

Our response team will acknowledge receipt of the report within 48 hours and coordinate patch testing and release.
